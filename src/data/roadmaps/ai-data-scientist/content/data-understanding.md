# Data Understanding, Analysis and Visualization

## What you'll learn
Inspect a dataset before modeling so you can understand its quality, structure, distributions, relationships, and limitations.

### Topics to cover
- Data types, missing values, duplicates, and outliers
- Descriptive statistics and distributions
- Grouping, aggregation, and correlation
- Visualizing categorical and numerical variables
- Exploratory Data Analysis (EDA) and communicating findings

## Free learning resources
- [Pandas Getting Started Tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html) — official hands-on tutorials.
- [Seaborn Tutorial](https://seaborn.pydata.org/tutorial.html) — statistical visualization documentation.
- [Kaggle: Data Visualization](https://www.kaggle.com/learn/data-visualization) — free interactive lessons.
- [Kaggle: Pandas](https://www.kaggle.com/learn/pandas) — practical data manipulation lessons.

## Practice
1. Choose a public dataset and summarize its rows, columns, and data types.
2. Check missing values, duplicates, and suspicious values.
3. Create three charts and write one evidence-based observation for each.
