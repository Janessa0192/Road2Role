# Classic and Advanced Machine Learning

## What you'll learn
Study supervised and unsupervised learning methods, model evaluation, regularization, feature engineering, and ways to compare models fairly.

### Topics to cover
- Linear and logistic regression
- Decision trees, random forests, and gradient boosting
- Clustering and dimensionality reduction
- Train/validation/test splits and cross-validation
- Overfitting, underfitting, regularization, and data leakage
- Metrics appropriate to the task

## Free learning resources
- [Open Machine Learning Course](https://mlcourse.ai/book/topic01/topic01_intro.html) — lessons and practical material.
- [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) — official documentation and examples.
- [An Introduction to Statistical Learning (free book and labs)](https://www.statlearning.com/) — accessible theory and practical labs.
- [Pattern Recognition and Machine Learning — free PDF](https://www.microsoft.com/en-us/research/uploads/prod/2006/01/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf).
- [PRML notes, code, and notebooks](https://github.com/gerdm/prml) — community repository; use alongside the book.

## Practice
1. Train a baseline model and compare it with a tree-based model.
2. Select metrics for an imbalanced classification problem and explain your choice.
3. Identify a possible source of data leakage in a sample workflow.
