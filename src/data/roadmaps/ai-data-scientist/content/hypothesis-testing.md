# Hypothesis Testing

## What you'll learn
Use sample data to assess evidence for a claim while understanding uncertainty and the limits of statistical tests.

### Topics to cover
- Null and alternative hypotheses
- Significance level and p-values
- Type I and Type II errors
- Statistical power and sample size
- Confidence intervals and practical significance

## Free learning resources
- [OpenIntro Statistics](https://www.openintro.org/book/os/) — free textbook with hypothesis-testing material.
- [Penn State: STAT 200 — Hypothesis Testing](https://online.stat.psu.edu/stat200/lesson/6) — course notes.
- [Seeing Theory](https://seeing-theory.brown.edu/) — visual explanations of probability and inference.

## Practice
1. State null and alternative hypotheses for a question you can measure.
2. Explain a p-value without saying it is the probability that the null hypothesis is true.
3. Give an example of a Type I error and a Type II error.
