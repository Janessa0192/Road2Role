# Increasing Test Sensitivity

## What you'll learn
Learn how experiment design and statistical techniques can improve the ability to detect meaningful effects without misinterpreting results.

### Topics to cover
- Minimum Detectable Effect (MDE)
- Statistical power and sample size
- Variance reduction
- Pre-experiment covariates and CUPED/CUPAC ideas
- Practical trade-offs and experiment validity
