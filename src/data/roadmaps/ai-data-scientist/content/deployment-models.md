# MLOps and Model Deployment

## What you'll learn
Understand how to move a trained model from an experiment into a reproducible, monitored application.

### Topics to cover
- Reproducible data and training pipelines
- Model packaging and serving through an API
- Testing and versioning models
- Deployment, monitoring, drift, and rollback
- Data privacy, security, and responsible operation

## Free learning resources
- [Full Stack Deep Learning](https://fullstackdeeplearning.com/course/2022/) — course material on building and deploying ML systems.
- [Made With ML: MLOps](https://madewithml.com/) — free lessons and practical projects.
- [MLflow Documentation](https://mlflow.org/docs/latest/) — experiment tracking and model lifecycle tools.
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/) — build an API to serve a model.

## Practice
1. Package a small trained model behind a local API endpoint.
2. Record model parameters and evaluation metrics.
3. Describe how you would detect data drift and safely roll back a poor model release.
