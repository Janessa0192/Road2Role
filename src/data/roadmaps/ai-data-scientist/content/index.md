# AI and Data Scientist Roadmap Content

This folder contains topic-specific learning material for the AI and Data Scientist roadmap. Each Markdown file includes a short explanation, free learning resources, and practice tasks.

The frontend should map each roadmap node's content identifier to the matching Markdown filename. For example, `diff-calculus` should load `diff-calculus.md`. If the current UI expects a different Markdown format or frontmatter, keep that existing loader contract when integrating these files.
