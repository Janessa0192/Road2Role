# SQL

## What you'll learn
Query and transform structured data using relational databases.

### Topics to cover
- SELECT, WHERE, ORDER BY, and LIMIT
- Aggregations and GROUP BY
- INNER and OUTER joins
- Subqueries and common table expressions
- Window functions and NULL handling

## Free learning resources
- [SQLBolt](https://sqlbolt.com/) — interactive SQL lessons.
- [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html) — official tutorial.
- [SQLZoo](https://sqlzoo.net/wiki/SQL_Tutorial) — interactive exercises.
- [SQL Tutorial](https://www.sqltutorial.org/) — reference and examples.

## Practice
1. Filter and aggregate a table to answer a business question.
2. Join two tables and explain the join type.
3. Use a window function to rank rows within groups.
