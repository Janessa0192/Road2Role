# Python

## What you'll learn
Use Python to write readable programs and work with data for analysis and machine learning.

### Topics to cover
- Variables, types, conditions, loops, and functions
- Lists, dictionaries, sets, and tuples
- Modules, exceptions, and file handling
- Virtual environments and package installation
- NumPy and pandas basics

## Free learning resources
- [Kaggle Learn: Python](https://www.kaggle.com/learn/python) — free interactive lessons.
- [Google's Python Class](https://developers.google.com/edu/python) — written lessons and exercises.
- [Official Python Tutorial](https://docs.python.org/3/tutorial/) — language reference and tutorial.
- [NumPy Learn](https://numpy.org/learn/) — learning material for numerical computing.

## Practice
1. Write functions to clean and summarize a small dataset.
2. Read a CSV file and handle missing values.
3. Use a dictionary to count category frequencies.
