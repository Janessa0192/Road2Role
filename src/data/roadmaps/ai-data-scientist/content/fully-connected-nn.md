# Neural Networks: Fully Connected, CNNs, RNNs, LSTMs, Transformers and Transfer Learning

## What you'll learn
Understand the main neural-network architectures, what kinds of data they suit, and how to train and evaluate them.

### Topics to cover
- Neurons, layers, activation functions, and loss functions
- Backpropagation and gradient-based optimization
- CNNs for image-like data
- RNNs and LSTMs for sequences
- Attention and Transformer architectures
- Transfer learning and fine-tuning

## Free learning resources
- [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) — visual explanation of Transformers.
- [Attention Is All You Need](https://arxiv.org/pdf/1706.03762.pdf) — original Transformer research paper.
- [Deep Learning Book](https://www.deeplearningbook.org/) — free online textbook.
- [Dive into Deep Learning](https://d2l.ai/) — interactive book with code examples.
- [PyTorch Tutorials](https://pytorch.org/tutorials/) — practical implementation guides.

## Practice
1. Train a small fully connected network on a simple dataset.
2. Explain why a CNN is a useful fit for image data.
3. Draw the high-level flow of self-attention in a Transformer.
4. Compare training a model from scratch with fine-tuning a pretrained model.
