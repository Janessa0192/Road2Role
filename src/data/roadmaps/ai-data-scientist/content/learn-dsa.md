# Data Structures and Algorithms

## What you'll learn
Practice choosing data structures and algorithms that make programs correct and efficient.

### Topics to cover
- Arrays, strings, hash maps, stacks, and queues
- Trees, graphs, and heaps
- Sorting and searching
- Recursion and basic dynamic programming
- Time and space complexity

## Free learning resources
- [LeetCode Learn](https://leetcode.com/explore/learn/) — topic-based practice.
- [LeetCode Study Plans](https://leetcode.com/studyplan/) — structured practice plans.
- [VisuAlgo](https://visualgo.net/en) — visualizations of common algorithms.
- [Open Data Structures](https://opendatastructures.org/) — free textbook.

## Practice
1. Solve one array or string problem and explain its complexity.
2. Implement a stack or queue.
3. Compare two approaches to the same problem and explain the trade-offs.
